# 数据来源说明（对应交付文件）

- 交付文件：`panel_30prov_2012_2023.csv`
- 范围：30省 × 2012-2023（360行）
- 说明：本交付文件**不包含** `*_filled` 外推字段

## 1) 交通运输业增加值

- 字段：`transport_value_added_100m_cny`
- 来源网站：国家统计局国家数据（分省年度）
- 链接：https://data.stats.gov.cn/easyquery.htm?cn=E0103
- 本地追溯：`priority1_output/data_stats_transport_value_added_long_30prov_2012_2023.csv`

## 2) 发电量（总/水/火）

- 字段：
  - `total_generation_100m_kwh`
  - `hydro_generation_100m_kwh`
  - `thermal_generation_100m_kwh`
- 来源网站：国家统计局国家数据（年度数据）
- 链接：https://data.stats.gov.cn/easyquery.htm?cn=C01
- 指标代码：A070308（总发电）、A070309（水电）、A07030A（火电）
- 本地追溯：
  - `priority1_output/a0703_three_series_raw.json`
  - `priority1_output/data_stats_clean_power_long_30prov_2012_2023.csv`

## 3) 燃油消费（汽油/柴油）

- 字段：
  - `gasoline_consumption_10k_ton`
  - `diesel_consumption_10k_ton`
- 来源网站：CEADs 省级能源清单
- 链接：https://www.ceads.net.cn/data/province/
- 覆盖：2012-2022（2023在本交付中留空）
- 本地追溯：`priority2_output/ceads_transport_gasoline_diesel_long_30prov_2012_2022.csv`

## 4) 新能源汽车保有量

- 字段：`nev_stock_10k`
- 来源说明：StarData 页面图表数字化整理（第三方），非官方分省原始数据库直出
- 参考链接：
  - https://www.stardata360.com/archives/1904 （2022）
  - https://www.stardata360.com/archives/4529 （2023）
- 本地追溯：
  - `output/nev_stock.csv`
  - `output/nev_stock_meta.json`
- 覆盖：2022-2023 有值，2012-2021 缺失

## 5) 公共充电桩（分省）

- 字段：`public_charging_piles`（单位：台）
- 来源文件：`cases/case01-nev-carbon/data/charging_piles_by_province.csv`
- 合并口径：按 `province + year` 左连接到交付面板（省名做后缀映射）
- 主要来源类型：A/B/C分级混合（政府网站、联盟发布、行业媒体）
- 代表来源：
  - https://www.sc.gov.cn/10462/10464/13298/13302/2022/4/25/35540a6804ff4c29ba7e726381bc29eb.shtml
  - https://mnewenergy.in-en.com/html/newenergy-2418053.shtml
  - https://chd.in-en.com/html/chd-2317718.shtml

## 6) 全国纯电动公交车（按年广播）

- 字段：`national_bev_buses`（单位：辆）
- 来源文件：`cases/case01-nev-carbon/data/national_ev_bus_annual.csv`
- 使用列：`national_bev_buses`
- 合并口径：按 `year` 左连接并广播到同年30省
- 代表来源：
  - https://xxgk.mot.gov.cn/jigou/zhghs/202006/t20200630_3321335.html （2019）
  - https://xxgk.mot.gov.cn/2020/jigou/zhghs/202205/t20220524_3656659.html （2021）
  - https://xxgk.mot.gov.cn/2020/jigou/zhghs/202306/t20230615_3847023.html （2022）
  - https://www.mot.gov.cn/ （2023公报入口）

## 7) 派生字段（脚本计算）

- `clean_generation_100m_kwh = total_generation_100m_kwh - thermal_generation_100m_kwh`
- `clean_power_ratio = (total_generation_100m_kwh - thermal_generation_100m_kwh) / total_generation_100m_kwh`
- `fuel_total_10k_ton = gasoline_consumption_10k_ton + diesel_consumption_10k_ton`
- `diesel_share_in_fuel = diesel_consumption_10k_ton / fuel_total_10k_ton`
- `fuel_intensity_per_100m_cny = fuel_total_10k_ton / transport_value_added_100m_cny`

相关脚本：`merge_all_priorities.py`
