# Chinese-First README Repositioning Design

**Date:** 2026-04-16  
**Scope:** Replace the current long README hero and framing with a shorter Chinese-first positioning that states clearly what the project is.

## Goal

Make the repository easier to understand for first-time visitors by:
- removing the banner,
- shortening the README,
- using Chinese as the primary landing language,
- defining the project directly by what it is, not by what it is not.

## Direction

The README should present the project as:

> 一个面向研究、竞赛与论文场景的可追溯数据采集与交付工具。

The top of the README should answer four questions quickly:
1. 这是什么？
2. 能做什么？
3. 适合谁用？
4. 怎么开始？

## Changes

1. Remove the banner from README.
2. Rewrite the top-level positioning in concise Chinese.
3. Shorten the overall README by moving advanced detail out of the main landing flow.
4. Keep only the most useful GitHub-facing sections:
   - 一句话定位
   - 核心能力
   - 适用场景
   - 快速开始
   - 代表案例
   - 文档入口
   - 贡献方式
5. Update GitHub repository description to match the new Chinese positioning.

## Success criteria

- README is visibly shorter.
- Banner no longer appears in README.
- The project is described positively and directly.
- GitHub repo description matches the new positioning.
