# v0.1.0 — Public Launch

Academic Data Hunter is now public.

This first release frames the project as **provenance-first infrastructure for auditable research data agents**: not just another agent wrapper, but a workflow layer for delivering datasets that can be checked, handed off, and defended.

## Highlights

- **Evidence Pack delivery**
  - Export a reusable delivery bundle with dataset, source registry, evidence records, and README.
- **Benchmark / Eval**
  - Score delivery quality with fill rate, provenance completeness, registry match rate, C-level cross-check rate, source quality score, and overall score.
- **MCP-ready tool surface**
  - Expose local workflow capabilities through a minimal MCP server for agent integrations.
- **Real cases**
  - Repository includes real case assets and benchmarked examples rather than only toy demos.
- **Public OSS polish**
  - CI badge, issue templates, pull request template, stronger README hero, and repository topics/metadata are now in place.

## What this repo is optimized for

- research workflows that need **traceable sources**
- datasets that need **validation / QC**
- handoff artifacts that need **evidence and reproducibility**
- agent systems that should output **auditable data assets**, not just plausible text

## Included in this release

- provenance-aware workflow docs and templates
- evidence pack exporter
- benchmark / eval pipeline
- MCP server documentation and entrypoint
- public-facing showcase, positioning, roadmap, and use-case docs
- contributor-facing GitHub templates and verification workflow

## Proof points

Real benchmark result from `cases/case01-nev-carbon`:

- fill rate: **40.95**
- provenance completeness: **100.00**
- registry match rate: **100.00**
- C-level cross-check rate: **100.00**
- source quality score: **59.53**
- overall score: **73.26**

## Why this matters

Most agent demos stop at “the model found something.”  
This project focuses on whether the result is **usable, reviewable, and defensible** in actual research or competition settings.
