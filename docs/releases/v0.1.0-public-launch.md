# v0.1.0 — 首次公开发布

Academic Data Hunter 已正式公开。

这个版本将项目明确定位为：

> **面向研究、竞赛与论文场景的可追溯数据采集与交付工具**

它关注的不是“找到一点信息”，而是把数据整理成**可继续分析、可回溯来源、可交接复核**的交付结果。

## 本次发布包含

- **Evidence Pack**
  - 导出包含数据表、来源台账、证据记录和说明文件的完整交付包
- **Benchmark Eval**
  - 从填充率、来源完整性、来源匹配率、交叉核验等维度评估交付质量
- **MCP Server**
  - 通过最小化本地 MCP server 暴露核心工作流能力
- **真实案例**
  - 仓库内包含可直接查看和复用的真实案例，而不是只停留在演示级样例
- **公开仓库基础设施**
  - CI、Issue 模板、PR 模板、公开说明文档等已补齐

## 适用场景

- 需要**可追溯来源**的数据收集任务
- 需要**字段校验与质量控制**的数据整理任务
- 需要**可交付、可复核**结果包的研究型工作流
- 需要给 AI Agent 接入**数据层与证据层**的场景

## 当前提供的能力

- 任务模板与工作流文档
- Evidence Pack 导出
- Benchmark / Eval 评估
- MCP Server 入口
- 案例、方法、路线图与贡献文档

## 一个真实结果
