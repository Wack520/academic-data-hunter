# Evidence Pack

Evidence Pack 是 workflow 的核心交付物之一。

它把数据表、来源台账、证据记录和说明文件一起交付出去，让结果可以复核、交接和继续分析。

## 当前结构

- `dataset.csv`
- `source_registry.csv`
- `evidence_records.jsonl`
- `README.md`
- `manifest.json`
