# 如何用 AI Agent 搜集学术数据

## 适用的 AI Agent

| Agent | 优势 | 适合的阶段 |
|-------|------|-----------|
| **Antigravity** | Web搜索 + 文件编辑 | 初步搜索、编写任务文档、QC合并 |
| **Codex** | 自主执行 + 浏览器自动化 | 逐省系统搜索、批量操作 |
| **Claude / ChatGPT** | 长文本理解 | 分析搜索结果、提取数字 |
| **Manus** | 联网搜索 + 浏览器 | 中等复杂度搜索（建议拆小任务） |

## 核心原则

### 1. 先给规范，再让搜索

❌ 错误做法：
```
"帮我搜各省充电桩数据"
```

✅ 正确做法：给标准化任务文档（见 [task-spec-template.md](../templates/task-spec-template.md)），包含：
- 变量定义和口径
- 搜索关键词模板
- 输出CSV格式
- 来源分级规则
- 红线约束（禁止估算）

### 2. 分批给任务

❌ 一次给全部8年30省
✅ 一次给1-2年，做完汇报再继续

### 3. 要求统一汇报格式

每轮让AI汇报：
```markdown
### 本轮结果
- 新增 X 条数据
- 来源：[URLs]
- QC：province+year 重复=0
- 覆盖变化：YYYY年缺失 N→M 省
```

## Antigravity + Codex 并行模式

```
┌─── Antigravity ───┐     ┌──── Codex ────┐
│ 1.搜索获取初始数据  │     │               │
│ 2.编写任务文档      │────→│ 3.按文档系统搜索 │
│ 4.审查Codex结果    │←────│ 5.汇报+QC      │
│ 6.合并去重入库      │     │               │
└───────────────────┘     └───────────────┘
```

### 给 Codex 的 Prompt 要点

1. **先给进度文件路径**（让它知道已有哪些数据）
2. **给明确的停止条件**（如"连续3省搜不到就停"）
3. **要求它更新进度文件**（而不是只在对话中回复）
4. **强调红线**（禁止估算、必须有URL）

### 示例 Prompt

```
请阅读 d:\path\to\进度汇报.md 获取当前进度。

继续执行充电桩数据补充，专攻2022年缺失省份。策略：
1. 优先搜索A/B级来源
2. 逐省搜索："{省名} 公共充电桩 2022 保有量 台"
3. 连续3省搜不到即停止
4. 新数据追加到CSV，跑合并+QC
5. 更新进度汇报文件
```

## 常见坑

| 坑 | 应对 |
|----|------|
| AI编造数据 | 要求每条附URL，抽查验证 |
| 口径搞混（新增vs保有） | 在任务文档中用❌明确禁止 |
| 单位换算错 | 要求在note中注明原始单位 |
| 重复入库 | QC脚本检查 province+year 唯一 |
| 来源过时/失效 | 记录access_date，及时存证 |
