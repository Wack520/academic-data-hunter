# 来源策略

项目允许使用不同类型的公开来源，但采用“高质量来源优先”的规则。

## 优先顺序

1. 政府 / 国际组织 / 官方数据库
2. 高校 / 论文附录 / 学术补充材料
3. 行业协会 / 智库 / 研究机构
4. 媒体 / 第三方网页

## 入库原则

- 所有来源都可以搜索
- 不是所有来源都能同等强度入库
- 来源越弱，越需要 cross-check
- 如果高等级来源与低等级来源冲突，以高等级来源为准

## 最低要求

入库记录至少要有：

- `source_url`
- 来源等级
- `access_date`
- 必要时的 `cross_check_url`
