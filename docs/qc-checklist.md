# QC 检查清单

## 单条数据入库前

- [ ] **来源URL存在**：`source_url` 不为空
- [ ] **URL可访问**：点击能打开（或至少搜索时可访问）
- [ ] **单位正确**：已统一为目标单位（如"万台"→"台"需×10000）
- [ ] **口径匹配**：确认是"年末保有量"而非"年度新增量"
- [ ] **来源分级**：已标注 A/B/C
- [ ] **C级交叉**：C级来源是否有 `cross_check_url`
- [ ] **时间点明确**：note中标注"截至XXXX年XX月"

## CSV文件整体检查

- [ ] **唯一性**：`province + year` 组合不重复
- [ ] **记录数一致**：非空行数 = 预期数据条数
- [ ] **编码**：UTF-8 / UTF-8-BOM
- [ ] **省份名一致**：所有省份名使用统一格式
- [ ] **年份范围**：不超出目标范围

## 合并到面板后检查

- [ ] **行数不变**：合并前后总行数一致（如360行）
- [ ] **新列非空统计**：打印每列非空数，与源表匹配
- [ ] **来源ID对齐**：有值的行都有对应 `source_id`
- [ ] **数值合理性**：最大/最小/均值是否在合理区间
- [ ] **同步导出**：CSV和XLSX同步更新

## QC 自动化命令

```bash
python tools/qc_checker.py data/my-data.csv \
  --key province,year \
  --required source_url \
  --check-unit 台
```
